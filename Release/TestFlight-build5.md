# TestFlight 1.0（5）

2026年11月7日の内部テスト用ビルドです。App Store公開用の旧ビルド4から、転がる車輪の発電箱へ変更しています。

- 右上から購入した車輪を投入し、円形の衝突で乱雑に積み上げる。
- 同じ種類を9体以上購入できる。
- 指の位置を基準にピンチで拡大し、二本指で自由に移動する。
- 揺らすボタンの連打で箱の中身を混ぜる。発電とは独立した操作。
- 箱と背景、車輪は同じカメラを使う。
- 配置と運動中の状態を保存し、売店で購入して閉じる前に終了しても既存の配置を保つ。
- 点サイズ同士の衝突を簡略化し、全個体の収入と発電ポップアップは保持する。
