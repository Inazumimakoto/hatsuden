連打でみんなが発電

ゲージを溜めて電球が点いたら、タップに合わせて仲間たちが一斉に発電。ゲーム内のお金を集めて、新しい仲間を迎えます。

部屋の外は、宇宙まで

室内の机やパソコン、庭、街、火山、港、宇宙。一枚の手描きの世界が、動物たちと一緒に少しずつ広がります。

留守中もコツコツ

アプリを閉じている間の発電量は、次に開いたときに所持金へ加算されます。ピンチで小さな仲間の様子を見に戻ることもできます。

ゲーム内に表示されるお金は、仲間を購入するためのゲーム内通貨です。本アプリにはバナー広告、起動時広告、任意の動画広告があります。
